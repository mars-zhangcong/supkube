# SupKube MVP Phase 1 — 产品需求文档 (PRD)

## 概述

- **产品名称：** SupKube
- **版本：** MVP Phase 1
- **目标：** 为 Velero 提供 Kasten K10 风格的 Kubernetes 数据保护 UI，覆盖备份/恢复核心流程
- **技术栈：** Go + Gin（后端）、Vue 3 + Element Plus（前端）、Helm Chart（部署）
- **目标用户：** Kubernetes 集群管理员、DevOps 工程师
- **参考产品：** Kasten K10 by Veeam

## MVP Phase 1 范围

Phase 1 聚焦**核心备份恢复流程**，对标 Kasten POC 测试项 1/3/4/16：
- 命名空间全量备份
- 指定资源备份
- 同集群恢复
- 备份列表与状态查看
- 备份存储配置

---

## 页面 1：Dashboard（仪表盘）

**功能描述：** 系统首页，提供集群数据保护状态的全局视图。

**用户故事：**
- US-1.1 [P0] 作为集群管理员，我希望看到集群概览（节点数、命名空间数、受保护应用数），以便了解集群规模
- US-1.2 [P0] 作为集群管理员，我希望看到备份状态摘要（成功/失败/进行中数量），以便快速发现异常
- US-1.3 [P0] 作为集群管理员，我希望看到最近 10 条备份活动，以便跟踪最新操作
- US-1.4 [P1] 作为集群管理员，我希望看到存储使用量，以便规划存储容量

**验收标准：**
- 页面加载后 3 秒内展示集群概览数据
- 备份状态摘要实时反映 Velero backup 资源的 phase 字段
- 最近活动列表按时间倒序，显示备份名称、目标命名空间、状态、创建时间
- 点击活动条目可跳转到备份详情页
- 页面支持自动刷新（30 秒间隔）

---

## 页面 2：Applications（应用列表）

**功能描述：** 按命名空间展示集群中所有应用及其保护状态。

**用户故事：**
- US-2.1 [P0] 看到所有命名空间列表及工作负载数量
- US-2.2 [P0] 看到每个命名空间的保护状态（已保护/未保护）
- US-2.3 [P0] 看到每个命名空间的最后备份时间
- US-2.4 [P1] 从应用列表直接发起备份操作

**验收标准：**
- 列出所有非系统命名空间（排除 kube-system、kube-public、velero 等）
- 每个命名空间显示：名称、工作负载数、保护状态、最后备份时间
- 支持按保护状态筛选
- 点击「立即备份」跳转到创建备份表单，自动填入命名空间

---

## 页面 3：Backups（备份管理）

**功能描述：** 备份核心管理页面。对标 Kasten 测试项 3（全量备份）和测试项 4（指定资源备份）。

**用户故事：**
- US-3.1 [P0] 看到所有备份列表（名称、状态、命名空间、创建时间、过期时间）
- US-3.2 [P0] 手动创建命名空间全量备份
- US-3.3 [P0] 通过标签选择器创建指定资源备份
- US-3.4 [P0] 查看备份详情（资源列表、大小、日志）
- US-3.5 [P1] 删除过期备份

**验收标准：**
- 列表显示：名称、命名空间、状态（New/InProgress/Completed/Failed）、创建时间、过期时间、存储位置
- 创建表单：备份名称、目标命名空间、标签选择器（可选）、TTL（默认 720h）、存储位置
- 提交后显示进度，完成后列表自动更新
- 详情页显示资源数量和类型、大小、开始/完成时间、日志
- 删除需二次确认

---

## 页面 4：Restores（恢复管理）

**功能描述：** 从已有备份恢复数据。对标 Kasten 测试项 3/4（同集群恢复）。

**用户故事：**
- US-4.1 [P0] 从备份列表选择恢复点发起恢复
- US-4.2 [P0] 恢复前预览将要恢复的资源列表
- US-4.3 [P0] 查看恢复历史（状态、时间、来源备份）
- US-4.4 [P2] 跨命名空间恢复（Phase 2）

**验收标准：**
- 恢复入口：备份详情页「恢复」按钮 + 恢复页面选择备份
- 恢复配置：来源备份、目标命名空间（Phase 1 默认原命名空间）、资源过滤
- 提交后显示进度状态
- 历史列表：恢复名称、来源备份、状态、时间、恢复资源数
- 失败时显示错误信息和日志

---

## 页面 5：Policies（备份策略）

**功能描述：** 定时备份策略管理。对标 Kasten 测试项 16。

**用户故事：**
- US-5.1 [P0] 创建定时备份策略（命名空间 + 调度时间）
- US-5.2 [P0] 配置保留策略（保留数量或天数）
- US-5.3 [P0] 查看策略列表及执行状态
- US-5.4 [P1] 暂停/恢复策略

**验收标准：**
- 列表：名称、目标命名空间、调度规则、状态（Active/Paused）、最后/下次执行时间
- 创建表单：名称、命名空间、调度（Cron + 可视化选择器）、TTL、存储位置
- 可视化选择器：每天/每周/每月/自定义
- 策略对应 Velero Schedule CRD
- 暂停 = Schedule paused=true

---

## 页面 6：Storage Locations（存储位置）

**功能描述：** 管理备份存储目标。MVP 支持 S3 兼容存储。

**用户故事：**
- US-6.1 [P0] 查看已配置的存储位置及连接状态
- US-6.2 [P0] 添加新的 S3 兼容存储位置
- US-6.3 [P1] 设置默认存储位置
- US-6.4 [P1] 验证存储连接

**验收标准：**
- 列表：名称、Provider、Bucket、状态（Available/Unavailable）、是否默认
- 添加表单：名称、Provider、Bucket、Region、Endpoint、Access Key、Secret Key
- 提交后创建 BackupStorageLocation CRD + Secret
- 30 秒内反馈连接状态
- 删除需确认无关联备份

---

## 页面 7：Settings（系统设置）

**功能描述：** 系统级配置和状态信息。

**用户故事：**
- US-7.1 [P0] 查看 Velero 连接状态和版本
- US-7.2 [P0] 查看集群基本信息（K8S 版本、节点数）
- US-7.3 [P1] 查看 SupKube 版本信息

**验收标准：**
- 显示 Velero Deployment 状态、Pod 状态、版本号
- 显示 K8S 版本、节点数量和状态
- Velero 不可用时显示错误提示和排查建议

---

## 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 页面首次加载 < 3s，API 响应 < 1s |
| 兼容性 | Chrome/Firefox/Edge 最新版本 |
| 部署 | Helm Chart 一键部署 |
| 安全 | MVP 单用户无认证（Phase 2 加 RBAC） |
| 国际化 | MVP 英文（Phase 2 中文） |
