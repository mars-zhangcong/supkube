# 冒烟:证明云端 runner 管道(clone→GPT→commit→PR)

## 目标
- 验证云端 runner 管道的基本流程，包括代码克隆、调用 GPT 生成代码、提交代码、创建 PR，确保各环节正常工作。

## 改动点
- 配置云端 runner，支持自动拉取代码仓库（clone）。
- 集成 GPT 服务，自动生成或修改代码。
- 实现自动 commit 并推送至远端仓库。
- 自动创建 Pull Request（PR）以触发后续流程。

## 验收
- 能成功拉取指定代码仓库。
- GPT 能正常生成或修改代码并保存至本地。
- commit 和 push 操作无误，代码成功推送至远端。
- PR 能自动创建，显示正确的变更内容。
- 全流程日志无异常，关键节点有明确输出。

## 风险
- GPT 生成代码质量不可控，可能导致 commit 内容不符合预期。
- runner 权限配置不当，可能导致 push 或 PR 操作失败。
- 网络或服务异常，影响流程稳定性。
- PR 自动化流程可能与现有仓库保护策略冲突。
